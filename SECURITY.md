# Security

Ballotta is a single static page: no server of its own, no accounts, and nothing a visitor types leaves their browser
except the address they look up, sent straight to Travis County's map server (and, when the county can't place it, the
U.S. Census address finder). The README says exactly what the page sends and where.

**To report a problem privately,** use **Feedback & Info** on [ballotta.org](https://ballotta.org): it opens an email to
the maintainer. Please don't open a public issue for anything that could hurt voters before it's fixed, such as a way to
change what the page shows, to read someone's picks, or to send data anywhere the page says it doesn't.

Fixes ship as new versions (see `CHANGELOG.md`); the live version is at https://ballotta.org/version.json.
